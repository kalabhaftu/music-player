Rust + Slint Workspace

Developer & Architecture Reference

Technical documentation for music-player-core (headless Rust engine) and music-player-app (Slint UI + Win32 desktop host). Looking for downloads and user guides? Visit the main page.

Overview

Headless Core (crates/core)

SQLite WAL store, Lofty metadata reading, container-specific tag writers, scanner/watcher pipelines, LRCLIB client, queue/EQ state, and LibVLC FFI with zero UI toolkit dependencies.

Desktop Host (crates/app)

Slint UI views/modals, controller state orchestration, SMTC media controls, tray icon, taskbar thumbnail buttons, COM drag-and-drop, and child HWND video hosting.

Design & Code Rules

All UI tokens live in crates/app/ui/widgets.slint (Palette) per DESIGN.md, and all test code stays in dedicated test targets per AGENTS.md.

Cold Start & Deferred Initialization

  1. Parallel LibVLC Pre-Warm: Before constructing AppWindow, a background thread (AudioEngine::prepare_vlc) loads libvlc.dll and plugins concurrently while Slint initializes the window.
  2. Non-Blocking First Frame: App::startup() populates settings, navigation, folder roots, and restored queue metadata from SQLite without blocking on LibVLC or Windows COM endpoint enumeration.
  3. Post-Paint Hydration: Once ui.show() paints the main window and dismisses the splash, complete_deferred_startup() attaches LibVLC, enumerates MMDevice outputs, restores paused track position, refreshes smart playlists, and triggers incremental scanning.

Library Scanner & SQLite WAL

  • Artwork Cache Snapshot: LibraryScanSession snapshots cached artwork filenames in memory once per scan rather than calling stat() per track.
  • Mtime + Size Fast Path: Unchanged files (matching byte length, UTC timestamp, lyrics flag, and cached artwork) are marked seen in batched 1,024-row SQLite statements.
  • Bounded Parallel Pipeline: New or changed files stream into a 2–4 worker HybridMetadataEngine pool and a dedicated single SQLite writer actor.
  • Safe Pruning: Unseen tracks are pruned only inside completed, reachable roots while protecting offline drives and reparse points.

Audio, Equalizer & Child HWND Video

  • Equalizer & Volume: Quadratic perceptual volume curve + 10-band ISO equalizer (32 Hz–16 kHz) with 20 presets.
  • Non-Blocking Crossfade: Dual-player state machine (Opening → Holding → Ramping) using DirectSound per-stream volume.
  • Video Hosting: VideoWindow attaches a Win32 child HWND via libvlc_media_player_set_hwnd using mmdevice output, supporting embedded + nearby sidecar subtitles.

Build, Test & Packaging

# Check all targets without producing binaries
cargo check --all-targets

# Run full workspace tests (unit, integration, app, benchmark_validation)
cargo test --workspace

# Build optimized release binary
cargo build --release --bin music-player-app

# Build local Inno Setup installer (requires Inno Setup + PowerShell 7)
pwsh -NoProfile -File .\packaging\windows\Build-LocalInstaller.ps1 -RebuildApp

Legacy .NET Workspace (legacy/)

The retired WinUI 3 + WebView2 application (legacy/src/MusicPlayer.App/), shared .NET 10 library (legacy/src/MusicPlayer.Core/), and experimental Avalonia 11.2 prototype (legacy/src/MusicPlayer.Desktop/) are preserved under legacy/ for historical reference and parity checks.
